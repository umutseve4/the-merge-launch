# Security Policy

## Scope

This repository is a static, self-contained fictional portfolio demo. It has no application backend, authentication boundary, production credentials or server-side contact-form processing.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting interface if it is available for this repository. If no private channel is available, open a public coordination issue containing only a high-level description and request a private contact path.

Do not publish exploit details, credentials, personal data or other sensitive evidence in a public issue, pull request or discussion.

## Useful report content

When a private channel is available, include the affected file or workflow, bounded reproduction steps, likely impact and a suggested mitigation if known.

The contact form does not transmit or store submitted values. Do not enter real secrets or sensitive personal information when testing it.
